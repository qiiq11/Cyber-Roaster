## 遇到的挑战与解决方案

| 挑战 | 解决方案 |
| --- | --- |
| 前端进度条视觉单调 | 使用三段渐变（青→黄→粉）模拟「混乱度」视觉冲击 |
| 统计接口被频繁调用 | 预留限流方案（slowapi 可插拔），默认 60/min |
| 跨域问题 | 后端 CORS 中间件全开放 + 前端 Vite 代理双保险 |
